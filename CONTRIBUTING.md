# Как добавить инструмент

Спасибо за интерес к проекту!

## Правила

1. **Актуальность** — сервис работает на момент добавления.
2. **Описание** — одно-два предложения на русском языке, без рекламы.
3. **Категория** — инструмент добавляется в подходящий файл в `categories/`.
4. **Формат** — таблица `| Инструмент | Описание |` со ссылкой в первом столбце.
5. **Бесплатность** — если сервис платный, укажите это в описании.
6. **Легальность** — только инструменты для работы с открытыми данными и проверки собственных данных.

## Как прислать правку

1. Fork репозитория.
2. Создайте ветку `feature/название`.
3. Внесите изменения.
4. Откройте Pull Request с описанием: что добавляете и почему это полезно.

## Идеи для развития

- Добавление новых категорий (например, `22-gameint.md` — игровые профили).
- Проверка мёртвых ссылок и их обновление.
- Перевод описаний на английский.

## Источники

Проект агрегирует и перерабатывает материалы открытых русскоязычных подборок (см. [21-obuchenie.md](categories/21-obuchenie.md)). При добавлении инструмента из чужого списка укажите источник в описании PR.
