Каталог инструментов и сервисов для OSINT, пробива и поиска информации, сгруппированный по категориям.
Собрано из открытых русскоязычных подборок (`osint-and-search`, `solkogan/osinto`, `OldBonhart/Osint-Resources`,
`OSINT-PROBIV`, `BuddyOsint`, `soxoj/counter-osint-guide-ru` и других) и адаптировано в единую структуру.

> ⚠️ **Правовое предупреждение.** Все инструменты приведены в ознакомительных и образовательных целях.
> Использование применимо к собственным данным или по прямому согласию владельца. Сбор и распространение
> персональных данных без согласия запрещён (см. ст. 137 УК РФ, ФЗ «О персональных данных»).

## 🚀 Быстрый старт

1. Определите тип исходных данных (телефон, email, ник, фото, адрес...).
2. Откройте соответствующий файл категории.
3. Начинайте с бесплатных инструментов, платные — при необходимости глубины.
4. Перепроверяйте результат в 2–3 независимых источниках.
