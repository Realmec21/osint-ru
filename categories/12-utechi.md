# 💥 Утечки и базы данных

Поиск по сливам, дампам и открытым базам. Проверка, не скомпрометированы ли ваши данные.

## Проверка себя (безопасно и законно)

| Сервис | Описание |
|--------|----------|
| [Have I Been Pwned](https://haveibeenpwned.com/) | Email и телефоны в утечках |
| [LeakCheck](https://leakcheck.net) | Поиск по базам утечек |
| [DeHashed](https://www.dehashed.com/) | Глубокий поиск по дампам (платно) |
| [Intelligence X](https://intelx.io/) | Поисковик по утечкам, документам, доменам |
| [Firefox Monitor](https://monitor.firefox.com/breaches) | Мониторинг утечек с уведомлениями |
| [psbdmp.ws](https://psbdmp.ws/) | Поиск по пастам Pastebin |
| [Have I Been Zuckered](https://haveibeenzuckered.com/) | Утечки Facebook |

## Публичные агрегаторы

| Ресурс | Описание |
|--------|----------|
| [Offshore Leaks](https://offshoreleaks.icij.org/) | Офшорные компании (ICIJ) |
| [DDoSecrets](https://data.ddosecrets.com/file/) | Расследовательские дампы |
| [danwin1210.me](https://danwin1210.me/uploads/) | Публичные загрузки утечек |
| [vigilante.pw](https://vigilante.pw/) | Уведомления об уязвимостях |
| [ebaza.pro](https://ebaza.pro/) | Поиск по открытым базам |

## Открытые базы (поиск через Shodan)

- [Shodan](https://www.shodan.io/) — поиск незащищённых баз данных, камер, устройств.
- [LeakLooker](https://github.com/woj-ciech/LeakLooker) — автоматизация поиска открытых баз.
- [Censys](https://censys.io/) — инвентаризация интернет-хостов.

## Пароли

- [Hashes.org](https://hashes.org/leaks.php) — разбор хешей из утечек.
- [Pwned Passwords](https://haveibeenpwned.com/Passwords) — проверка пароля через k-анонимат (пароль не покидает устройство).

> ⚠️ Доступ к чужим дампам и паролям третьих лиц — нарушение закона. Проверяйте только свои данные.
