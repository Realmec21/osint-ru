# 🌐 Домены, IP и серверы

Разведка по доменам, IP-адресам, серверам и инфраструктуре.

## Whois и DNS

| Сервис | Описание |
|--------|----------|
| [WHOIS (ICANN)](https://whois.icann.org/en) | Данные о домене: владелец, даты, NS |
| [Domaintools WHOIS](https://whois.domaintools.com/) | История WHOIS-записей |
| [ViewDNS](https://viewdns.info/) | Набор инструментов: IP history, reverse IP |
| [DNSDumpster](https://dnsdumpster.com/) | Визуализация DNS и подсетей |
| [crt.sh](https://crt.sh/) | Сертификаты: поиск поддоменов |
| [SecurityTrails](https://securitytrails.com/) | История DNS и связанные домены |

## Инфраструктура

| Сервис | Описание |
|--------|----------|
| [Shodan](https://www.shodan.io/) | Поиск устройств, сервисов, баннеров по IP |
| [Censys](https://censys.io/) | Сканирование всего интернета |
| [Netcraft](https://www.netcraft.com/) | Определение ОС, хостинга, веб-сервера |
| [Pingdom tools](https://tools.pingdom.com/) | Проверка сайта из разных точек мира |
| [builtwith.com](https://builtwith.com/) | Технологии, использованные на сайте |
| [w3techs.com](https://w3techs.com/) | Статистика веб-технологий |
