# 📱 Мессенджеры

OSINT в Telegram, WhatsApp, Discord, ICQ и других мессенджерах.

## Telegram

| Инструмент | Описание |
|------------|----------|
| [TGStat](https://tgstat.ru/) | Аналитика и поиск по каналам, архив постов |
| [Telega.in](https://telega.in/) | Каталог каналов со статистикой |
| [Telega.org](https://telega.org/) | Мониторинг Telegram-рекламы и каналов |
| [Telesint](https://t.me/telesintitbot) | Группы и чаты пользователя, поиск по никам |
| [TeleScan](https://t.me/TScan_RUEKG_Robot) | Подписки пользователя на группы и чаты |
| [buzz.im](https://search.buzz.im/) | Поиск по чатам Telegram |
| [Telegago](https://bit.ly/Telegago) | Поиск по статьям в Telegram через Google CSE |
| [Social Searcher TG](https://www.social-searcher.com/) | Поиск упоминаний |

Методы: ID канала/пользователя узнаётся через `@username` или ссылки пересылки; архивные копии постов доступны через TGStat; упоминания ищутся по нику в кавычках.

## WhatsApp

| Инструмент | Описание |
|------------|----------|
| [Whatsap.de](https://whatsap.de/) | Проверка по номеру |
| [WaLook](https://walook.com/) | Определение фото профиля по номеру |
| [WhatsApp Web**](https://web.whatsapp.com) | Экспорт переписк из своих чатов для анализа |

## Discord

| Инструмент | Описание |
|------------|----------|
| [Discord.com/users](https://discord.com/users/ID) | Профиль по ID |

| [Disboard](https://disboard.org/) | Поиск серверов |
