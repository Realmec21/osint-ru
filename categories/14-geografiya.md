# 🗺️ Геолокация и карты

Определение места съёмки, поиск по карте, веб-камеры, геометки.

## Определение локации

| Инструмент | Описание |
|------------|----------|
| [Google Maps](https://maps.google.com) | Спутник, Street View, измерения |
| [Yandex Карты](https://yandex.ru/maps/) | Спутник, «Яндекс.Улицы», бизнес |
| [OpenStreetMap](https://www.openstreetmap.org/) | Открытые карты с детализацией |
| [Wikimapia](https://wikimapia.org/) | Народные метки объектов на карте |
| [Google Earth Web](https://earth.google.com/web/) | 3D-модели и история снимков |
| [Sentinel Hub](https://apps.sentinel-hub.com/) | Бесплатные спутниковые снимки |
| [NASA Worldview](https://worldview.earthdata.nasa.gov/) | Архив снимков NASA |

## Спутник и история снимков

- [Google Earth Pro (десктоп)](https://www.google.com/earth/) — исторические снимки по годам.
- [Yandex «Яндекс.Улицы»](https://yandex.ru/maps/) — панорамы с датами съёмки.
- [Mapillary](https://www.mapillary.com/) — уличные панорамы от пользователей.

## Веб-камеры

| Сервис | Описание |
|--------|----------|
| [EarthCam](https://www.earthcam.com/) | Камеры по всему миру |
| [Insecam](http://insecam.org/) | Каталог открытых камер |
| [WorldCam](https://worldcam.eu/) | Популярные камеры городов |
| [Jawcam / Camera maps](https://www.earthcam.com/) | Камеры по странам |

## Геометки и следы

- [photomap](http://sanstv.ru/photomap/) — фото по геометкам в соцсетях.
- [YouTube Geofind](https://mattw.io/youtube-geofind/location) — видео, снятые в конкретной точке.
- [snradar](http://snradar.azurewebsites.net/) — фото ВК по времени и месту.
- [aprs.fi](https://aprs.fi) — геолокация радиолюбительских меток.
- [3WiFi map](https://3wifi.stascorp.com/map) — карта Wi-Fi точек доступа.
- [MAC → геолокация](https://alexell.ru/network/mac-geo/) — приблизительное определение по MAC роутера.

## Полезные приёмы

- Тени, номера домов, госномера, вывески и язык указателей — основные маркеры локации.
- Измеряйте расстояния через объекты с известным размером (знаки, полосы, столбы).
- Сочетайте обратный поиск фото ([05-foto-i-litsa.md](05-foto-i-litsa.md)) с картографией.
