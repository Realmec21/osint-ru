# 🪙 Криптовалюты

Разведка по блокчейнам: отслеживание транзакций, атрибуция кошельков, оплата сервисов.

## Обозреватели блокчейнов

| Сервис | Описание |
|--------|----------|
| [Blockchain.com](https://www.blockchain.com/explorer) | Биткоин: поиск транзакций и адресов |
| [Etherscan](https://etherscan.io/) | Ethereum: транзакции, контракты, токены |
| [Blockchair](https://blockchair.com/) | Мультичейн поисковик |
| [BTC.com](https://btc.com/) | Статистика Bitcoin |
| [Solscan](https://solscan.io/) | Solana |
| [Tronscan](https://tronscan.org/) | TRON (часто используется для USDT) |

## Расследования и атрибуция

| Сервис | Описание |
|--------|----------|
| [Arkham](https://arkhamintelligence.com/) | Метки адресов и связи кошельков |
| [Chainalysis](https://www.chainalysis.com/) | Институциональный блокчейн-развед |
| [Crystal](https://crystalblockchain.com/) | Анализ криптопотоков |
| [Maltego + plugins](https://www.maltego.com/) | Связи между адресами в расследованиях |

## Миксеры и конвертация

- Миксеры и privacy-кошельки усложняют трекинг — учитывайте при анализе потоков.
- P2P-обменники оставляют след в переписке и объявлениях — ищите ID сделок в кавычках.

## Оплата сервисов

Часть OSINT-ботов принимает оплату криптой. Встроенные кошельки в Telegram (например, [Antarctic](https://t.me/antarctic_wallet_bot)) позволяют покупать криптовалюту за рубли и оплачивать по QR-кодам.
