# 🔬 Форензика и метаданные

Анализ файлов: EXIF, метаданные, проверка подлинности изображений и документов.

## EXIF и метаданные

| Инструмент | Описание |
|------------|----------|
| [ExifTool](https://exiftool.org/) | Ключевая утилита: чтение и правка метаданных |
| [metapicz.com](http://metapicz.com/#landing) | Онлайн-просмотр EXIF |
| [findexif.com](http://www.findexif.com/) | Извлечение EXIF в браузере |
| [Jeffrey's EXIF viewer](http://exif.regex.info/exif.cgi) | Детальный разбор метаданных |
| [linkstore.ru/exif](http://linkstore.ru/exif/) | Онлайн EXIF |
| [imgops.com](http://imgops.com/) | Обратный поиск + метаданные |

JPEG со смартфона с включённым GPS обычно содержит координаты съёмки в EXIF.

## Проверка подлинности фото

| Инструмент | Описание |
|------------|----------|
| [FotoForensics](http://fotoforensics.com/) | Анализ ELA: следы редактирования |
| [29a.ch level sweep](https://29a.ch/photo-forensics/#level-sweep) | Визуализация уровней сжатия |
| [Ghiro](https://ghiro.org/) | Автоматизированный анализ изображений |

## Аудио и видео

| Инструмент | Описание |
|------------|----------|
| [Amplitude spectrum](https://29a.ch/) | Спектральный анализ аудио |
| [InVID / WeVerify](https://weverify.eu/) | Проверка видео и колтажей |
| [Forensically](https://29a.ch/photo-forensics/) | Набор инструментов форензики |

## Документы и файлы

- [Adobe Experience Manager metadata](https://www.adobe.com/) — чтение PDF-метаданных.
- [Toolsley](https://www.toolsley.com/) — определение типа файла по сигнатуре.
- [Google Docs viewers](https://docs.google.com/) — извлечение текста из сканов (OCR через Google Keep/Docs).
- `strings` / [CyberChef](https://gchq.github.io/CyberChef/) — просмотр скрытых данных в файлах.

## Текст

- [Advego Plagiatus](http://www.advego.ru/plagiatus/) — поиск первоисточника текста.
- [Инструменты проверки на ИИ-текст](https://originality.ai/) — оценка вероятности генерации.
