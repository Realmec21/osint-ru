# 🤖 Telegram-боты для OSINT и пробива

Каталог Telegram-ботов, используемых для поиска информации. Условные обозначения:
`📲` — бот · `🌐` — сайт · `🪙` — платный · `🆓` — есть бесплатный лимит · `♻️` — может не работать с РФ-аккаунтами

| Метки | Бот | Возможности |
