# 🏷️ Никнеймы и логины

Поиск аккаунтов человека по псевдониму: где зарегистрирован ник, связанные профили.

## Чекеры никнеймов

| Сервис | Описание |
|--------|----------|
| [NameChk](https://namechk.com) | Проверка доступности ника на сотнях площадок |
| [KnowEm](https://knowem.com) | Проверка ника как юзернейма и товарного знака |
| [NameCheckr](https://www.namecheckr.com) | Универсальная проверка ников |
| [User Sherlock](http://usersherlock.com) | Поиск ника на сайтах |
| [User Searcher](https://usersearch.org) | Поиск по 2000+ ресурсов |
| [Instant Username](https://instantusername.com) | Быстрая проверка ника на ключевых платформах |
| [Sherlock](https://github.com/sherlock-project/sherlock) | Консольный инструмент: поиск юзернейма по сотням сайтов |
| [Maigret](https://github.com/soxoj/maigret) | Fork Sherlock с расширенными возможностями и проверкой сайтов |
| [WhatsMyName](https://github.com/WebBreacher/WhatsMyName) | Каталог сайтов для поиска юзернеймов |

## Специализированные

| Сервис | Описание |
|--------|----------|
| [SteamID](https://steamid.io/) | Идентификаторы Steam, история никнеймов |
| [VIPChecker](https://vipchecker.ru/) | Проверка аккаунтов Minecraft |
| [GHNames](https://github.com/GHNames) | История имён и email в GitHub |

## Методы

- Наберите ник в адресной строке соцсети напрямую: `vk.com/nick`, `my.mail.ru/mail/nick`.
- Ищите ник в кавычках — так находятся упоминания на форумах, в коде, в дампах.
- Уникальный ник даёт наибольшую отдачу: одно совпадение связывает профили между площадками.
- Пользователи меняют ник — проверяйте старые варианты с цифрами и разделителями (`_`, `-`, `x`).
