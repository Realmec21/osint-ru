# 💻 Социальные сети

Разведка по профилям в соцсетях: VK, Одноклассники, Instagram, Facebook, X, YouTube, TikTok и другие.

## ВКонтакте

| Инструмент | Описание |
|------------|----------|
| [Поиск людей ВК](https://vk.com/search?c%5Bsection%5D=people) | Встроенные фильтры: город, учёба, работа |
| [vkdia.com](https://vkdia.com/) | Анализ связей по совместному времени онлайн |
| [220VK](https://220vk.com/) | Анализ реакций, комментариев и активности |
| [searchlikes.ru](http://searchlikes.ru) | Анализ лайков пользователя |
| [VKAnalysis](https://github.com/migalin/VKAnalysis) | Скрипт анализа VK |
| [TopDB](https://topdb.ru) | Удалённые изображения по ID пользователя |
| [Упоминания в ВК](https://vk.com/feed?obj=ID&q=%C2%A7ion=mentions) | URL-шаблон поиска упоминаний по ID пользователя |

ID пользователя ВК узнаётся наведением курсора на кнопку «Отправить сообщение» или на аватар.

## Одноклассники

- Встроенный поиск по ФИО с фильтрами по городу и дате рождения.
- Публичные альбомы и записи на стене доступны без подписки.

## Зарубежные платформы

| Платформа | Инструменты |
|-----------|-------------|
| Instagram | [Picuki](https://www.picuki.com/), [InstagramOSINT](https://github.com/sc1341/InstagramOSINT), [Dumpor](https://dumpor.com/) |
| X (Twitter) | [twint](https://github.com/twintproject/twint), [Twitter advanced search](https://twitter.com/search-advanced), [twitter-intelligence](https://github.com/batuhaniskr/twitter-intelligence) |
| Facebook | [Поиск друзей](https://www.facebook.com/friends/requests/), [FB search](https://www.facebook.com/search/top/) |
| YouTube | [YouTube Geofind](https://mattw.io/youtube-geofind/location) — видео по геоточке |
| LinkedIn | Встроенный поиск с фильтрами по компаниям и должностям |
| Reddit | [Redditsearch](https://redditsearch.io/), [reddit user analysis](https://www.reddit.com/user/USERNAME/about.json) |
| TikTok | Публичные профили, [Urlebird](https://urlebird.com/) |

## Универсальные

- [Social Searcher](https://www.social-searcher.com/) — мгновенный поиск по соцсетям.
- [Namechk](https://namechk.com), [Sherlock](https://github.com/sherlock-project/sherlock) — поиск одного ника по всем площадкам (подробнее в [04-niki.md](04-niki.md)).

## Методы

- Встроенное «умное» ведение (совместные фото, комментарии) часто ценнее сторонних сервисов.
- Скриншотите результаты: профили удаляются быстрее, чем проводится расследование.
- Смотрите список групп и подписок — они отражают интересы и связи человека.
