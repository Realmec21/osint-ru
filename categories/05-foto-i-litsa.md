# 📷 Фото и лица

Обратный поиск по изображениям, поиск людей по фото, извлечение метаданных.

## Обратный поиск изображений

| Сервис | Описание |
|--------|----------|
| [Yandex Картинки](https://images.yandex.ru) | Сильнейший обратный поиск для рунета и лиц |
| [Google Images](https://images.google.com) | Обратный поиск + продвинутые фильтры ([advanced](https://www.google.com/advanced_image_search)) |
| [TinEye](https://www.tineye.com) | Поиск первоисточника картинки и всех доменов, где она размещена |
| [Berify](https://berify.com) | Обратный поиск с расширенным охватом |

## Геометки фото

- [worldc.am](http://worldc.am/) — фото с привязкой к геолокации.
- [snradar](http://snradar.azurewebsites.net/) — фото ВК, сделанные в определённое время и месте.

## Методы

- В поиске по картинке добавляйте текстовый запрос и фильтр региона (`site:se` для Швеции).
- На фото ищите вывески, номера автомобилей, отражения в окнах, особенности ландшафта.
- Масштаб объектов считайте через объекты с известными размерами (знаки, столбы, двери).
- Проверяйте фото мошенников и фейков: [scamdigger.com](http://scamdigger.com/picsearch.php).
