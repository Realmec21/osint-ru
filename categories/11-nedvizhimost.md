# 🏠 Недвижимость и кадастр

Поиск собственника по адресу, проверка объектов, кадастровые данные.

## Официальные сервисы РФ

| Сервис | Данные |
|--------|--------|
| [Публичная кадастровая карта](https://pkk5.rosreestr.ru/) | Кадастровые номера, границы, стоимость |
| [Росреестр: справочная информация](https://rosreestr.ru/wps/portal/cc_information_online) | Данные по объектам недвижимости |
| [Росреестр: запрос о правах](https://rosreestr.ru/wps/portal/p/cc_ib_portal_services/online_request) | Владелец квартиры (по адресу/кадастровому номеру) |
| [ЕГРН.Реестр](https://egrnreestr.ru/) | Публичные сведения из ЕГРН |
| [Кадастровая стоимость](https://kadastrmap.com/) | Упрощённый поиск по кадастровому номеру |
| [domclick](https://domclick.ru/) | Ипотечные объекты Сбера |

## Поиск по адресу

| Сервис | Данные |
|--------|--------|
| [ФИАС](https://fias.nalog.ru/) | Официальный адресный классификатор |
| [Яндекс Карты](https://yandex.ru/maps/) | Фото, оценки, бизнес по адресу |
| [2ГИС](https://2gis.ru/) | Организации и здания |
| [Федеральный адресный реестр](https://flat.restate.ru/) | Собственники по адресам (частично) |

## Методы

- Номер квартиры + адрес в кавычках часто выводит на объявления о продаже/аренде с контактами.
- Кадастровый номер ищется на публичной карте, затем запрашивается выписка.
- Домашний адрес подтверждается совпадением данных из телефонной книги, досок объявлений и реестров.
