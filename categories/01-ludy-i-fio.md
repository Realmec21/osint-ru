# 👤 Люди и ФИО

Поиск человека по имени, фамилии, дате рождения и комбинации личных данных.

| Сервис | Описание |
|--------|----------|
| [Pipl](https://pipl.com/) | Мировой поисковик людей, агрегирует соцсети и публичные записи |
| [PeekYou](https://www.peekyou.com/) | Поиск людей по имени и фамилии в соцсетях и блогах |
| [That'sThem](https://thatsthem.com/) | Агрегатор публичных записей: адреса, телефоны, email |

| [Spokeo](https://www.spokeo.com/) | Социальный поиск людей: профили, адреса, история |
| [ZabaSearch](https://www.zabasearch.com/search_menu/) | Публичные записи США |
| [Hunter](https://hunter.io/) | Поиск email-адресов по имени и компании |
| [NameLocator](http://www.nameslocator.com/) | Поиск людей по имени по разным странам |

## Соцсети и агрегаторы

| Сервис | Описание |
|--------|----------|
| [go.mail.ru/search_social](https://go.mail.ru/search_social) | Поиск людей по русскоязычным соцсетям |
| [Поиск людей ВК](https://vk.com/search?c%5Bsection%5D=people) | Встроенный поиск ВКонтакте с фильтрами (город, учёба, работа) |
| [where-you.com](https://where-you.com) | Объединённый поиск людей в соцсетях |

## Работа с ФИО

- Ищите имя и фамилию в кавычках в поисковиках — это сужает выдачу до точных совпадений.
- Если человек сменил ФИО, повторите поиск по старому варианту написания, по дате рождения, по городу.
- Дата рождения в связке с именем часто позволяет отсеять однофамильцев.
- Уточняющие фильтры в поиске ВК (возраст «от/до») позволяют вычислить скрытый год рождения: когда пользователь исчезает из выдачи, предыдущее значение — его возраст.
