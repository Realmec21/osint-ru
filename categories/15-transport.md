# ✈️ Транспорт: самолёты и суда

Отслеживание авиации и морского транспорта в реальном времени.

## Авиация

| Сервис | Описание |
|--------|----------|
| [Flightradar24](https://www.flightradar24.com) | Карта полётов в реальном времени |
| [FlightAware](https://flightaware.com/) | Трекер полётов и расписания |
| [PlaneFinder](https://planefinder.net/) | Отслеживание самолётов |
| [RadarBox](https://www.radarbox24.com/) | Данные ADS-B, история полётов |
| [ADS-B Exchange](https://globe.adsbexchange.com/) | Нефильтрованные данные, военная авиация |
| [AirNav Radar](https://www.airnavradar.com/) | Радар и история маршрутов |
| [Airportia](https://www.airportia.com/) | Статусы рейсов и история |

Методы: история рейсов по бортовому номеру, фото самолёта (споттеры) позволяют идентифицировать перевозчика; чартерные и спецрейсы отслеживаются через ADS-B Exchange.

## Морской транспорт

| Сервис | Описание |
|--------|----------|
| [MarineTraffic](https://www.marinetraffic.com) | Карта движения судов (AIS) |
| [VesselFinder](https://www.vesselfinder.com/) | Позиции и данные судов |
| [shipfinder.co](http://shipfinder.co/) | Поиск судов |

| [Maritime-connector](https://maritime-connector.com/) | База судовладельцев и флота |
