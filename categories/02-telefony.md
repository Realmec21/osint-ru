# 📱 Номера телефонов

Пробив номера телефона: определение владельца, оператора, региона, связей в соцсетях.

## Сервисы и боты

| Инструмент | Описание |
|------------|----------|
| [GetContact](https://play.google.com/store/apps/details?id=app.source.getcontact&hl=ru) | Приложение: как подписан номер в чужих телефонных книгах |
| [NumBuster](https://play.google.com/store/apps/details?id=com.numbuster.android) | Аналог GetContact с дополнительными данными |
| [SMSC HLR-тест](https://smsc.ru/testhlr/) | Проверка доступности номера и данных оператора |
| [@get_kontakt_bot](http://t.me/get_kontakt_bot) | Telegram-бот: отображение имени из чужих контактных книг |
| [@numberPhoneBot](https://t.me/numberPhoneBot) | Бот для пробива по РФ и Украине |
| [@mnp_bot](https://telegram.me/mnp_bot) | Определение оператора и переносов номера |
| [@xinitbot](https://t.me/xinitbot) | Определение региона и оператора |
| [doska-org.ru](http://doska-org.ru) | Поиск номера на досках объявлений |
| [zytely.rosfirm.info](https://zytely.rosfirm.info) | ФИО, дата рождения и адрес по номеру |
| [email2phonenumber](https://github.com/martinvigo/email2phonenumber) | Инструмент: поиск телефона по email |

## Методы

- **В поисковике в кавычках** — ищите номер с вариантами `+7` и `8`, заключив в двойные кавычки.
- **Импорт контактов** — добавьте номер в адресную книгу с VK, WhatsApp, Viber: при синхронизации видно, сидит ли человек в сервисе, и подтягивается аватар.
- **Адресные книги городов** — телефонные справочники СНГ с фамилиями и адресами: [nomer-org.me](http://nomer-org.me/), [spra.vkaru.net](http://spra.vkaru.net/).
- **Доски объявлений** — номер мог публиковаться в объявлениях о продаже, аренде, вакансиях.
