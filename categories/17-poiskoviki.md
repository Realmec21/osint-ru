# 🔎 Поисковики и докинг

Продвинутый поиск: докинги Google/Yandex, специализированные поисковики, поисковые комбайны.

## Google-докинг (операторы)

| Оператор | Назначение |
|----------|------------|
| `"фраза"` | Точное совпадение фразы |
| `site:example.ru` | Поиск по сайту |
| `filetype:pdf` | Поиск по типу файла |
| `intitle:"index of"` | Открытые директории |
| `inurl:admin` | URL с ключевым словом |
| `cache:example.ru` | Кэшированная версия страницы |
| `related:example.ru` | Похожие сайты |
| `"@gmail.com"` | Упоминания email в тексте |

Полный список: [Google Guide — operators](http://www.googleguide.com/advanced_operators_reference.html).

## Методы

- Сочетайте dorks: `site:vk.com "Иванов" "город" filetype:pdf`.
- Ищите упоминания ников и телефонов в кавычках на любых площадках.
- Real-time разделы (mail.ru) хорошо ловят свежие публикации.
